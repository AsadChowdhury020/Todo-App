# 📝 Todo List App (React + Tailwind CSS)

## 📌 Project Description
This is a simple Todo List application built using **React (Vite)** and styled with **Tailwind CSS**.  
The app allows users to:
- Add new tasks  
- Delete existing tasks  

This project demonstrates **React component architecture, state management, props passing, and reusable components**.

---

## 🛠️ Technologies Used
- React.js  
- Vite  
- Tailwind CSS  
- JavaScript (ES6+)  

---

---

## ▶️ Installation Instructions

1. Clone the repository  
```bash
git clone https://github.com/AsadChowdhury020/Todo-App
```

2. Navigate to project folder  
```bash
cd todo-app
```

3. Install dependencies  
```bash
npm install
```

4. Run the project  
```bash
npm run dev
```
